Практико-орієнтований підхід
Замість «вивчи й здай» — «зроби й покажи». Учень виходить з уроку з готовим цифровим результатом. Навчання = виробництво реального продукту.
🎮
Unity + C# для вивчення ООП
Об'єктно-орієнтоване програмування через створення ігор — найефективніший спосіб пояснити класи, об'єкти та методи підліткам. Вчимося граючи.
🐍
Python та алгоритмізація
Від базових алгоритмів до Python Turtle. Авторські практичні роботи, структурне програмування, власні програми як результат кожного модуля.
🧠
Генеративний ШІ у проєктах
ChatGPT, Midjourney, DALL-E — не як іграшки, а як інструменти. Учні генерують графіку, оптимізують код та генерують ідеї для своїх проєктів.
